Connection settings

The speed slider controls motion; the controller determines actual frame rate. Dark holds are omitted from full replacement frames to make rain and logos lighter to send. Auto uses API 2 when the board name has no @ suffix. If it connects but stays dark, disconnect and try API 3.

TAKE IT TO THE GYM

Four steps to
another dimension.

No account. No extra controller. No board firmware changes.

  1. Open on your laptop.

    Use Chrome or Edge on Windows or Mac with Bluetooth on. Android Chrome also works. On iPhone/iPad, open this URL inside Bluefy. Safari and ordinary iPhone Chrome can preview, but cannot connect.

  2. Match the wall.

    Choose the same layout, size, and hold sets as in the Kilter app. Disconnect the Kilter app and any other phone currently controlling the board.

  3. Connect, then test the corners.

    Allow Bluetooth and select the gym’s board. The test should light pink at top left, cyan at top right, yellow at bottom left, and green at bottom right. If it looks wrong, clear, disconnect, and check the size.

  4. Press Play on board.

    Start with The full trip or Rainbow vortex. Adjust motion and brightness as it runs. Stop & clear takes over after the current short packet. Disconnect now releases Bluetooth immediately if anything gets stuck; the last picture may remain lit. Reconnect with the Kilter app when done.

A real Bluetooth show, with one honest caveat.

Animation playback has worked on a real board. This update to Stop and effect switching has passed software checks and still needs a gym retest. Full-wall updates can be much slower than the screen preview. The app shows the measured sending rate once connected. If Bluetooth drops or you close the browser, the last frame may stay lit — reconnect with the Kilter app to replace it.
